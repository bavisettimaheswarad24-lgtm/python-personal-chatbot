# MAHESH AI — Personal Python Question-Answering Chatbot

A clean, responsive, retro-futuristic AI chatbot engineered by **Mahesh** that exclusively answers **Python programming questions**.

---

### Features:
* **High-Performance Inverted Index**: Webpage queries execute in `< 1ms` using inverted document posting lists.
* **Strictly Python Questions**: Real Python questions only (Lists vs Tuples, Decorators, GIL, Mutable defaults, Generators, Asyncio, etc.).
* **Syntax-Highlighted Python Code**: Clean code blocks with copy answer buttons.
* **Dual-Hosting Ready**: Run locally with Flask or push directly to GitHub Pages.

---

### How to Run:
```bash
pip install -r requirements.txt
python app.py
```
Open `http://localhost:5000` in your browser.
